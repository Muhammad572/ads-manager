# MiniMates runtime assets

Served at `https://hastech.online/minimates/` via GitHub Pages (hastech.online).

- `manifest.json` — resolver contract read by the Roku app at launch.
- `v1/images/`, `v1/sounds/` — the runtime-downloaded assets (filenames identical to the source project).
- `placeholder.png` — shown while an asset downloads or on failure.

To publish updated art without a Roku rebuild: add a new `v2/` folder, bump `assetVersion` in `manifest.json`, commit, push.

Generated by `MiniMates-Roku/tools/asset_manifest.py`.
